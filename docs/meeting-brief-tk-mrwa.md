# TK 미팅 브리프 — Main Roads WA 가이드라인 × Prism (2026-07-31)

두 문서: **Operational Modelling Guidelines v2.0** (MRWA, 2021-01) + **Mesoscopic and Hybrid
Modelling Guidelines v1.0** (MRWA, 2021-07). 토론 구조(TK 요구 → 우리 응답 → 우리 제안)에
맞춰 정리. 핵심 결론 먼저: **이 가이드라인의 반복 후렴은 "모든 파라미터 변경을 기록하고
정당화하라"이고, 그건 Prism이 이미 구조적으로 하는 일입니다.**

---

## 0. 미팅 서두에 확인할 것 3가지

1. **보내주신 PDF는 146쪽에서 끝나는데, 문서 자체 목차는 Vissim 섹션(§5)이 179쪽부터입니다.**
   1~2장(공통 절차) + 3장(LinSig)만 담겨 있고 **§5 Vissim, §4 SIDRA, 부록 A(신호 데이터)·
   B(포화 교통류)가 빠져 있습니다.** Prism이 구동하는 건 Vissim이므로 §5와 부록 A·B를
   요청하세요 — 거기에 Vissim용 GEH 기준치와 Wiedemann 파라미터 규칙이 있을 것입니다.
2. **Murdoch 모델의 심사 카테고리(1/2/3)가 무엇인지** — 카테고리에 따라 검증 항목
   (Table 2-2: 대기행렬/포화류/교통량/통행시간/신호시간)과 수치 기준이 달라집니다.
   Prism 검증 대시보드를 어느 기준에 맞출지가 여기서 결정됩니다.
3. **meso/hybrid 문서를 왜 보내셨는지** — 현 Murdoch 모델은 순수 micro입니다(6개 노드
   전부 `useForMeso=false`, 우리가 실측). 향후 meso/hybrid 과제가 있다는 신호라면
   로드맵 논의 대상입니다(아래 §4).

## 2. 우리 제안 (TK가 묻지 않아도 꺼낼 것)

① **MRWA 제약 팩** — 가이드라인의 수치를 그대로 제약 카탈로그에 넣습니다: 회전교차로
임계 gap 최소 2.1s/1.5s(op p.53), follow-up headway 표 2-4~2-7의 기하별 허용 범위, meso
Table 7-15의 회전유형별 critical/follow-up gap. **"설정값이 MRWA 표 범위를 벗어나면
경고로 해당 페이지를 인용"** — 감사관이 볼 문서를 시스템이 미리 읽고 있는 셈. 지금 90개
제약에 기관 출처 인용 구조가 이미 있어(WSDOT/Maryland 사례) 작업량이 작습니다.

② **변경 이력 → MRWA 제출용 보고서 export** — 승인 시 정당화 사유 한 줄을 필수 입력으로
받으면, "파라미터 변경 기록+근거" 섹션이 자동 생성됩니다. 문서 전체가 요구하는 바로 그
산출물.

③ **카테고리 인지형 검증 프로파일** — Cat 1/2/3 × 전체/핵심 구역의 GEH·R²·RMSE·통행시간
기준을 드롭다운으로. (meso 기준은 표로 확보; micro 기준은 §5 수령 후.)

④ **BusDwell 질문** — 곡선 5개([0,5]~[20,30]s)가 왜 미연결인지 + meso Table 5-4의 dwell
시작값(15~45s)과 어긋나는 이유. 의도된 미완성인지, 잊힌 작업인지.

## 3. 솔직하게 "아직 안 됩니다" (먼저 말해서 신뢰 획득)

- **SCATS/SCATSIM·감응식 신호(VAP)**: 현재 verb는 고정시간 프로그램 내 주기/녹색시간까지.
  감응 로직·SCATSIM 연동은 미지원 (§5·부록 A 보고 판단).
- **DoS/PRC/MMQ 산출**: LinSig 중심 지표. Vissim 노드 평가 기반으로 만들 수는 있으나 현
  대시보드는 지연/LOS/통행시간/대기행렬 중심.
- **OD 행렬 추정·조정(ODME), 신규 객체 생성(링크·신호두 등)**: v2b/v2c 로드맵 — 시기 약속
  없이 방향만.
- **meso/hybrid**: 모델 전환·meso 파라미터 verb는 미착수. 단, meso critical/follow-up gap이
  conflict area 속성이라 기존 verb 기반과 연속성 있음 — 수요 있으면 다음 큐 후보.

## 4. 참고 수치 카드 (토론 중 인용용)

- GEH 공식 √[2(M−C)²/(M+C)]; meso 기준(Cat1/2/3): GEH<5 →85/82.5/80%(전체)·90/87.5/85%(핵심), R²>0.95/0.925/0.90, RMSE<15/20/25%, 통행시간 ±15% 또는 ±1분 중 큰 값(합격률 90/85/80%)
- 신호 검증(meso): 주기 ±5초, 페이즈 녹색 ±3초 (SCATS 평균 대비)
- 잠재수요 <1%(base), 시드 ≥5, meso Vissim 수렴: 경로 통행시간 ±15%, 수렴 경로 90/85/80%, 연속 4회
- PCU: Austroads 1=1.0 / 2-5=2.0 / 6-9=3.0 / 10-11=4.0 / 12=5.0; 1 PCU=7.35m
- 데이터: 피크당 최소 3시간, 통행시간 관측 ≥6회, 대기행렬 표본 ≥10/시간, 중립일 원칙
- 문서는 **비규범적**(op p.5) — 대안적 방법론은 Main Roads 재량으로 수용 가능 ← AI 보조
  워크플로를 정당화할 때 인용할 문장
