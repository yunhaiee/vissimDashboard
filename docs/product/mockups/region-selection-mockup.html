제외된 구간·블록은 생성에서 빠집니다. 경계에 걸친 간선은 유지되고, 제외 블록의 내부 이면도로만 빠집니다. 생성 후 검증 게이트(V1–V9)를 통과해야 완료로 표시됩니다.

디자인 오픈 질문 — 이 목업으로 확인하고 싶은 것

  1. 선택 시작 방식: 라쏘(그리기)가 기본인가, 아니면 "교차로 하나 클릭 → 연결된 도로로 자동 확장(seed & grow)"이 더 자연스러운가?
  2. 제외의 단위: 블록 제외 시 내부 도로만 빠지고 경계 간선은 남는 현재 규칙이 기대와 일치하는가? (지금 블록 모드로 직접 확인 가능)
  3. 경계 처리: 라쏘에 절반만 걸린 구간은 지금 "포함"으로 처리 — 잘라야 하나, 통째로 넣어야 하나, 물어봐야 하나?
