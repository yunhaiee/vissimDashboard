## 1막 — 진단: 거부가 이유를 측정으로 말한다 (3분)

`2712071437d0` 상세 페이지를 엽니다.

1. **V7 검사 셀**의 소견 하나를 클릭 → 처분 카드를 읽습니다. 예전엔 "교정값이
   제공되지 않았다"는 일반 문구였지만, 지금은 **측정 결과**가 적혀 있습니다:
   *"드래프트 자신의 기록도 이미 같은 폴리라인 — 손상은 드래프트보다 상류."*
   **멘트**: AI가 좌표를 지어내서 고치는 건 금지입니다(승인자가 좌표를 넣어도
   거부합니다 — 좌표는 발명하지 않는다). 대신 왜 못 고치는지를 측정해서 말합니다.
2. **V3 검사 셀** → `둔산로 [FWD]` 소견 클릭 → 카드에 **소스 증언**이 있습니다:
   *"원본 OSM이 way 1294765723이 node 414675514를 공유하며 출발 가능하다고
   증언한다 — 공백은 세계가 아니라 파이프라인의 것."*
   **멘트**: 같은 "길 끊김"이라도 두 종류입니다. 원본 지도에 길이 있으면 우리가
   잃어버린 것이고, 원본부터 막혔으면 세상이 그런 겁니다. 28건을 전수 심문해
   5:23으로 갈랐고, 각각 way/node 번호까지 답합니다.

## 2막 — 치료: 증언이 제안이 되고, 질문이 카드가 된다 (5분)

1. 같은 둔산로 소견 카드에서 아래로 — **add_connector 제안**이 있습니다:
   from 링크 400 → to 링크 1637, 스팬 5.7m, 그리고 정직한 경고까지: 이 이동은
   **U-턴(152.6°)**이고 생성기가 원래 "전부 U-턴이라 안 지었다"고 판정한 자리라는
   것이 근거문에 그대로 인용돼 있습니다.
   **멘트**: 연결 사실의 출처는 원본 지도, 기하 구성만 기계가 합니다. 승인은
   ask-first — 지도를 확인했다는 체크 없이는 버튼이 잠깁니다. (승인하면 실제
   Vissim COM으로 커넥터가 생성되고 형제 잡이 재판정됩니다 — 시연 시 1~2분.)
2. `d31961abd950` 상세 → V3 소견 → **증언 카드**:
   *"실제 도로가 여기서 이어집니까? 도달 가능한 링크 끝 5개…"* — to-link 선택과
   근거 문장이 **필수**이고, 누가·언제는 서버가 도장을 찍습니다(요청에 그 필드
   자체가 없어 위조 불가).
   **멘트**: 원본 지도도 모르는 곳은 현장을 아는 사람이 증언합니다. 30초짜리
   예/아니오로 바뀐 모델링 세션 — 그리고 그 증언은 감사 기록에 이름과 함께
   남습니다.

## 3막 — 근치: 재생성 버튼, 그리고 사라지는 소견들 (5분) ★하이라이트

`b3ef6abb9a85` 상세를 엽니다 (작아서 빠릅니다).

1. V7 소견 카드 → **"재생성으로 치료"** 버튼과 설명: 산출물을 편집하는 게 아니라
   **같은 소스에서, 고쳐진 변환기로 다시 뽑는다** — 원인(같은 way가 두 번 선언됨,
   Overpass union의 서명)과 변환기 수정 이력이 명시돼 있습니다.
2. 클릭 → 새 잡이 큐에 들어가고 정상 파이프라인+판사를 그대로 통과합니다.
3. 완료된 재생성 잡을 엽니다: **v7 5건 → 0건, v3 2건 → 0건.** 판정은
   refused → incomplete (신호·수요가 아직 없으니 완성은 아니라고 정직하게 말함).
   부모 잡은 바이트 하나 안 바뀌고 그대로 — 진단 증거는 보존됩니다.
   **멘트**: 열쇠(#34)를 만들었더니 자물쇠가 상류에 있다는 측정이 나왔고, 상류를
   고쳤더니(#38) 실소스 전체에서 156건이 0건이 됐습니다. 아무것도 지어내지 않고요.
   (큰 잡 `2712071437d0`도 같은 버튼으로 62→0 — 시간 여유 있으면 한 번 더.)

주의: side-input(수요/신호)이 합성된 잡은 재생성이 **명명 거부**됩니다 — 더 얇은
산출물을 조용히 만드느니 거부한다는 원칙 그대로. 데모 잡들은 해당 없음.

## 4막 — V1 버튼: "진짜 Vissim이 열어봤다" (2분)

아무 gated 잡(예: 재생성으로 방금 만든 잡)의 **V1 셀** → **"실 Vissim으로 확인"**.

- Vissim이 실제로 떠서 파일을 열고, V1이 `확인 불가` → **합격**으로 바뀝니다.
  증거 basis는 `app_observed` — 사람이 증언한 것과 앱이 측정한 것을 구분해 적습니다.
- 이전 판정은 `gate_history/`에 바이트 그대로 보관 — **판정은 사라지지 않습니다.**
- (참고: 데모 교차로 잡 `2f7ef25fec02`는 이미 이 버튼의 라이브 증명이 완료된 상태)
