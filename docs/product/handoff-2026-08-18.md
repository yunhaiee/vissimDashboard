사용자 질문에서 출발해 텍스트북·논문·코드를 4갈래로 조사한 결과:

이미 전사된 발췌: `docs/product/reference/mrwa-section5-extract.md`(§5 전체 84소절 + 17개 표), `mrwa-linsig-tables-extract.md`, `mrwa-appendix-a/b-extract.md`.

**(b) 지침이 규정한 보정 순서** (§2.12.1, 13단계, 문서 p.34–42)
① 기본 네트워크 코딩 → ② 차량 속도 → ③ 비신호 교차로 → ④ 블로킹 → ⑤ 회전 차로 → ⑥ 신호 교차로 → **⑦ 정지선 포화교통류** → ⑧ 차로 이용률 → ⑨ 대중교통 → ⑩ **수요 보정** → ⑪ **경로 선택** → ⑫ **행태 파라미터** → ⑬ 소프트웨어별.
원칙: *"한 번에 파라미터 하나씩"*, *"검증 데이터는 보정에 쓴 데이터와 독립"*, *"§2.12.1.11 경로 선택은 교통량 보정 **전에** 확인"*.

**(c) 인풋이 다 실측인데 GEH가 높을 때의 답** (§5.2.5.1, 문서 p.187–188)
> *"기본 주행 행태를 채택하되 **차량추종 모델 파라미터**와 waiting time before diffusion은 예외로 관측 거동을 반영해 조정한다."* 조정 대상: **정지 간격 2.5 m**, **additive/multiplicative part of safety distance는 핵심 교차로의 측정된 직진 포화교통류에 근거해 결정**.

**Table 5-6** (문서 p.187) — 측정값 → 파라미터 **룩업**:

| 측정 포화교통류(pcu) | Additive | Multiplicative |
|---|---|---|
| 1,630 | 2.75 | 3.75 |
| 1,780 | 2.50 | 3.50 |
| 1,950 | 2.25 | 3.25 |
| 2,050 | 2.00 | 3.00 |
| 2,100 | 1.75 | 2.75 |
| 2,200 | 1.50 | 2.50 |

→ **"AI가 감으로 튜닝"이 아니라 측정 → 표 조회.** 우리 원칙(발명 금지·출처 인용)과 완벽히 맞음. **그리고 이 표는 이미 `mrwa_reference.py`에 전사돼 있는데 코드 주석이 스스로 "no consumer wires this table"이라고 적고 있음.**

합병 구간은 별도 파라미터 집합(안전거리 감소계수 0.25–0.45, 협조적 제동 −5.00~−9.00 m/s², 협조적 차로변경/인접차로 관찰 체크, 측방거리 0.1–0.4 m / 0.2–1.0 m).
비신호는 Table 5-9(임계 간격 3–8 s, 추종 헤드웨이 2–5 s), 충돌영역은 Table 5-10(front 0.5–1.0 s, rear 2.0–4.0 s, 합류 1.5–3.0 s).

**(d) 수용 기준** — MRWA Table 5-12/5-13/5-14 (전사본: `mrwa-section5-extract.md:1174-1274`)
- 교통량: 카테고리별 GEH<5 **95/85/80%**, GEH<10 **100/95/90%** + 흐름 밴드 + R²
- **지정 핵심 교차로는 개별적으로 GEH<5** (네트워크 기준을 통과해도 별도 적용 — 더 엄격)
- 통행시간: **15% 또는 1분 중 큰 값**, 통과율 100/90/85%
- 신호 시간(Table 5-14): 방향이 반대 — **작은 값** 기준, 감응식 행은 숫자 없음
- 포화교통류 **±10%**; **대기행렬은 Vissim 장에 수치 허용오차가 없음**(정성적)
- 미회수: Table 2-3(카테고리별 어떤 기준이 적용되는지)은 체크표 이미지라 텍스트 추출 불가 — OCR 필요

**(e) 표준 실무** (외부, 인용 있음)
FHWA Traffic Analysis Toolbox Vol III(2004): **용량 → 경로 선택 → 시스템 성능** 3단계, GEH<5/85% 규칙의 출처. FHWA 2019판은 **GEH를 버리고** 다일 변동 범위 기준으로 이동(= "FHWA GEH<5"를 인용하면 2004판 인용). TxDOT·영국 TAG M3.1도 같은 순서.

**(f) 우리 코드의 실제 능력** (측정)
