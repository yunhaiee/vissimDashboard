## 장면 D — 신호가 시계를 읽는다 (#70) — 장면 C에서 계속

1. "signals 입력 만들기" 버튼 **위의 체크박스 "시간대 자동 전환 포함"** 을 본다.
   - ✓ **기본은 꺼짐** — 안 켜면 이전과 완전 동일 동작 (바이트 동일, 골든 핀).
2. 체크 켜고 스테이징 → CTA로 재생성 → 잡 요약을 본다.
   - ✓ 시트의 시간대 문구가 파싱된 계획들은 **프로그램 여러 개 + 전환 스케줄**로
     들어가고, 파싱 안 된 계획은 **계획별 경고**(어느 계획, 어느 문구, 왜)가
     잡 요약에 뜬다 — 경고가 전체 생성을 죽이지 않는다.
   - 참고: 대전 시트의 "TOD1 00:00, TOD2 00:00" 같은 **합의된 요일형은 하나로
     병합**되고, "TOD1 21:00, TOD2 06:00" 같은 진짜 불일치만 거부된다.
3. (기록 확인) 잡 요약의 schedule_element_verified.
   - ✓ **true + 2026-08-26 + 검증 계기** — 라이브 Vissim SaveNetAs 왕복에서
     스케줄 요소가 축자 생존(가정 S7 해소)한 실측 기록이다.
