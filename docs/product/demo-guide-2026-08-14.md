> 설명하면서 직접 클릭할 사람(=당신). 각 단계마다 **무엇을 누르는지**, **화면에서

## 0. 준비 (5분)

1. **Vissim 2026 SP09**가 설치된 이 PC에서 진행합니다. Vissim을 **미리 열어둘 필요
   없습니다** — 오히려 열려 있어도 상관없습니다. 우리 자동화는 절대 열려 있는
   Vissim 창에 붙지 않고(`attach_to_running=False`), 항상 **자기만의 새 인스턴스**를
   띄웁니다. *비유: 남이 쓰고 있는 계산대를 빌리지 않고 새 계산대를 엽니다 —
   당신이 열어둔 작업이 절대 오염되지 않습니다.*
2. 백엔드(8001)·프론트(3000)가 떠 있는지: 브라우저에서 `localhost:3000` →
   **개요 페이지**가 뜨면 정상.
3. **로그인** (상단 바 계정 자리). 생성 시작·승인·라이브 체크는 전부 로그인 필요
   — 감사 문서에 "누가" 승인했는지가 남아야 하기 때문입니다.
4. 프로젝트 선택: 개요 제목 아래 드롭다운 또는 사이드바 상단. 데모용 프로젝트
   그대로 쓰면 됩니다.

## 1막 — B4: 생성에서 리포트까지 한 줄로 (약 20분)

### 1-1. 영역을 그려서 네트워크 만들기

**클릭 경로**: 사이드바 ① 네트워크 → 생성 → 우상단 **새 생성** → 모달에서
**영역에서 추출하기** → 지도 위에 폴리곤을 클릭으로 찍고 두 번 눌러 닫기 →
**이 영역 추출하기** → 추출이 끝나면 생성으로 이어짐.

- 지도 아래 **좌표 표**가 점 찍을 때마다 자동으로 채워지고, 숫자를 직접 고치면
  지도의 폴리곤이 즉시 따라 움직입니다.
- 넓이가 한계를 넘으면 추출 버튼이 **비활성**이 되고, 버튼에 마우스를 올리면
  "반경 X가 한계 Y를 초과" 같은 실제 수치가 뜹니다. **자르지 않고 거부합니다** —
  일부만 몰래 받아오는 일은 없습니다.

**속에서 일어나는 일**: 그린 폴리곤이 그대로 기준입니다. OpenStreetMap에
그 폴리곤으로 질의하고(**쿠키커터 비유**: 반죽=도로망, 커터=당신의 폴리곤),
폴리곤 밖으로 삐져나온 도로는 **변에서 잘라 그 자리에 노드**를 만듭니다.
"점이 폴리곤 안인가"는 레이캐스트 알고리즘 — *점에서 광선을 쏴서 테두리를
홀수 번 지나면 안, 짝수 번이면 밖* — 으로 판정합니다. 잘린 도로는 전부
이름이 남습니다(준수 리포트에 기록). **조용히 버리는 것이 이 제품의 금기**입니다.

### 1-2. 게이트가 판정하는 것을 보여주기

생성이 끝나면 이력 목록에 새 행이 생기고, **행을 클릭하면 그 생성의 상세
페이지**(고유 URL)가 열립니다. 왼쪽에 실지도 위 네트워크, 오른쪽에 V1–V9 그리드.

**게이트 = 준공검사관 아홉 명.** 건물(네트워크)을 지었다고 끝이 아니라, 아홉
검사관이 각자 자기 항목만 봅니다:

| 검사 | 한 줄 설명 | 비유 |
|---|---|---|
| V1 로드 오라클 | 실제 Vissim이 이 파일을 열었다는 **증거** | 소방서 실사 — 서류가 아니라 현장 방문 |
| V2 참조 무결성 | 없는 대상을 가리키는 참조 0건 | 각주가 전부 실제 페이지를 가리키는가 |
| V3 연결성 | 들어가면 나올 수 있는가 | 방마다 문이 있는가 |
| V4 차로 연속성 | 차로가 줄어들 때 미리 준비할 거리(활주로)가 있는가 | 고속도로 차선 합류 예고 표지 |
| V5 신호-기하 정합 | 신호가 실제 접근로와 맞는가 | 신호등이 없는 길을 향해 서 있지 않은가 |
| V6 수요 커버리지 | 교통량·구성·라우팅이 실려 있는가 | 배우 없는 무대인가 |
| V7 기하 위생 | 0-길이/겹친 링크 등 | 도면에 선이 두 겹으로 그어진 곳 |
| V8·V9 | 상충·계측 준비(경고 등급) | 권고 사항 |

핵심 원칙 두 개를 말로 설명하세요:
- **"실행 못 한 검사는 통과가 아니다"** — 확인 불가는 회색 태그로 남고, 절대
  초록으로 위장하지 않습니다.
- **거부돼도 파일은 받을 수 있습니다** — 판정과 파일은 아티팩트(↓ 버튼)로 그대로.
  *거부는 처벌이 아니라 진단서입니다(3막에서 치료합니다).*

### 1-3. 라이브 체크로 V1 닫기 (여기서 처음 COM)

통과/잠정 생성에 대해 라이브 체크를 실행합니다(런북 `b4-demo-runbook-2026-08-12.md`의
해당 명령 그대로):

```bash
cd backend && .venv/Scripts/python tools/genesis_open_live_check.py --job-id <잡ID>
```

Vissim이 **새 창으로 스스로 열리고**, 파일을 로드하고, 결과(state.json)를 남깁니다.
상세 페이지에서 라이브 체크를 붙이면 V1이 "확인 불가 → 진짜 판정"으로 바뀝니다.

**왜 이런 구조인가**: 오프라인 검사가 아무리 초록이어도 "실제 Vissim이 연다"는
별개의 사실입니다(우리가 실측으로 배운 교훈 — 오프라인 왕복은 자기일관성 증명일
뿐). 그래서 V1은 **열어본 기록 + 파일 지문(sha256) 일치**를 요구합니다. *영수증에
찍힌 바코드가 지금 손에 든 상품과 같은지 대조하는 것과 같습니다.*

### 1-4. 시뮬레이션 → 리포트

**클릭 경로**: ③ 시뮬·보정 → 대시보드 → 시뮬레이션 실행(런북 절차) → 끝나면
같은 페이지에서 KPI·**차량 궤적 재생**(런을 고르면 그 런의 궤적이 도식 위에서
재생) → ④ 보고서 → 작성에서 DOCX 내보내기.

**GEH 한 줄 설명**(질문 나오면): 관측량 M과 모형량 C의 차이를 교통공학 표준으로
잰 값 — `GEH = √( 2(M−C)² / (M+C) )`. *퍼센트 오차의 사촌인데, 큰 교통량과 작은
교통량을 한 자로 잴 수 있게 만든 것.* 관례상 **GEH < 5면 그 지점은 합격**입니다.

## 2막 — C1-b: 현시도 확인 클릭 (약 5분)

**클릭 경로**: ② 데이터 → 신호 (현시도) → 목록에서 교차로 하나 선택 →
모델이 읽어낸 제안(접근로↔현시 배정)을 실물 그림과 대조 → 맞으면 **확인**,
틀리면 고쳐서 확인 → signals 입력 만들기.

**속 원리 — 왜 사람 클릭이 필요한가**: 대전 신호 시트의 현시도는 **그림**입니다.
어떤 파서도 그림에서 "북쪽 접근로가 현시 2"라는 사실을 만들 수 없습니다. 그래서
비전 모델이 **제안**만 하고(105개 현시 중 104개가 스스로 "여긴 모호함"이라고
표시할 만큼 보수적으로), **사람의 확인 클릭이 데이터를 만듭니다**. *비유: 통역사
초벌 번역 + 원어민 감수 서명 — 서명 전에는 어떤 문서에도 못 들어갑니다.*
확인 전 제안은 3중으로 불활성(소스에 스킵 파라미터 없음·매핑 생성 불가·스테이징
409)이라, 실수로 새어 들어갈 길 자체가 없습니다.

이 클릭이 **이 제품의 첫 실제 인간 확인**입니다 — 데모 포인트로 강조할 것.

## 3막 — B5-2: 거부는 진단, 에이전트는 치료 (약 10분)

### 3-1. 거부된 생성의 상세 페이지로

이력에서 **거부됨** 행 클릭. 오른쪽 그리드에서 실패/확인 불가 검사를 클릭하면
소견 목록이 열리고, 소견마다 **처분**이 붙어 있습니다:

- **치료 불가**는 버튼이 아니라 **사유 문장**입니다. 예: 연결성 소견은
  `CONNECTIVITY_IS_NOT_INVENTED` — *지도 원본이 잇지 않은 길을 AI가 지어 붙이는
  순간 그건 수리가 아니라 위조*라서, 41개 소견 코드 전수가 "치료 가능/불가 중
  하나"로 미리 선언돼 있고 그 사이로 새는 코드는 테스트가 막습니다.
- **치료 가능**은 승인 카드: 어떤 도구로 무엇을 바꾸는지, 근거, 가정, 그리고
  값이 필요한 경우(예: 수요 볼륨) **당신이 직접 입력해야 승인 버튼이 풀립니다**
  (ask-first — *AI가 교통량을 지어내지 않습니다*).

### 3-2. 승인 → 형제 잡 관전

**적용 승인**을 누르면:

1. 거부된 원본은 **바이트 하나 안 바뀝니다** — 진단서는 보존됩니다. *환자 차트에
   덮어쓰지 않고 새 차트를 만드는 것.*
2. 복제본(형제 잡)에 승인된 수정 **하나만** COM으로 적용되고(가드레일이 "다른 건
   아무것도 안 움직였는지" 사전·사후 대조), 같은 게이트가 **다시** 판정합니다.
3. 화면이 자동으로 형제 잡의 상세 페이지로 이동 — 재게이트 판정이 도착하는 것을
   그대로 지켜봅니다. 헤더의 `파생 —` 줄이 "누가 어떤 소견으로 승인했는지"의
   계보입니다.

**안전장치 시연 멘트**(질문 대비): 승인 전에 서버가 ① 그 소견이 정말 부모 판정에
있는지 ② 파라미터가 정말 그 소견의 대상(예: 입력 113)을 가리키는지 ③ 측정된
입구가 아닌지(측정된 볼륨을 덮어쓰려 하면 이름 붙은 거부)를 전부 재검사합니다 —
적대적 테스트로 실제 우회를 만들어 보고 막은 것들입니다.

CLI로 하려면:

```bash
cd backend && .venv/Scripts/python tools/genesis_fix_loop_live_check.py --job-id <거부잡ID>
```

### 3-3. (선택) 보정 루프도 한 컷

시간이 남으면 어시스턴트 서랍(우측)에서 보정 데모: GEH가 높은 지점 → 제안 →
**제안 이유가 카드에 그대로 보이고**, 승인 사유를 적으면 감사 DOCX의 근거 칸에
남습니다. **D4 원칙** 한 줄: *실측 교통량은 과녁이지 조절 손잡이가 아니다* —
측정된 입구의 볼륨을 만지는 제안은 구조적으로 거부되고, 보정은 운전 행태·신호
같은 진짜 손잡이만 돌립니다.

## 문제가 생기면

| 증상 | 원인/조치 |
|---|---|
| 401 / 로그인 풀림 | 상단 바에서 재로그인. 승인·생성·라이브 체크는 전부 로그인 필요 |
| `workspace_forbidden` | 한 번 새로고침 — 자동 복구(거부된 프로젝트 헤더를 버리고 기본으로) |
| 지도가 대체 도형(SVG)으로 | 로그인 세션인지 확인. 정상 폴백이며 사유가 그대로 인용됨 |
| Vissim이 안 뜸 | 라이선스 좌석 확인. 우리 스크립트는 항상 새 인스턴스를 띄우므로 열린 창과 무관 |
| 잡이 안 끝남 | 이력 행이 1초 폴링으로 살아 있음 — 상세 페이지의 진행 %를 신뢰 |
