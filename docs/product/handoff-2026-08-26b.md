## 4. 이 세션 신규 트랩 (전 계정 공유)

1. **PowerShell `>`가 git 패치를 오염**: Out-File이 BOM+CRLF로 다시 써서 `git apply`가
   "patch does not apply"를 낸다(원인 은폐적 — 파일들이 main에서 안 바뀌었는데도 실패).
   **`git diff --output=<file>`로 생성하면 동일 diff가 깨끗하게 적용**된다. 실측 완료.
2. **핀의 주석 자기충족**: 슬라이스를 raw 소스에서 자르면 수정 설명 주석이 핀을 충족시킨다
   (#67 R1 D1 — CTA 클래스 3핀이 자기 주석으로 초록; AppShell:205 백틱 인용이 raw `shell`
   핀 사문화). 스타일/존재 핀은 `surface`/`withoutComments` 기준. 주석에 코드 문자열을
   백틱으로 축자 인용하는 것 자체가 핀 킬러가 될 수 있다.
3. **클래스 핀의 `\b` 함정**: `\b`는 하이픈 앞에서 성립 → `/bg-accent\b/`가
   `hover:bg-accent-deep` **안에서** 매치. 클래스 토큰 핀은 `(?![-\w])` lookahead 또는
   연속 런 고정으로.
4. **공유 프리미티브 수정 = 폭발 반경 공격 의무**: #59 R3가 `resolve_write_target`(모든
   배치 동사 공유)에 id 정규화를 넣었다 — 이런 수정은 반드시 전 호출처·전 id 어휘로
   재반박할 것(§2a 각도 ①이 그 지시문).
5. **에이전트 경로의 id는 초크포인트 하나에서 정규화**: #59 전쟁 3라운드의 관통 교훈 —
